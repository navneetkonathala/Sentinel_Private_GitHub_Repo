HOW THE ML MODEL WORKS

Train on normal.
Isolate the unusual.

An Isolation Forest is an unsupervised machine-learning model: it learns from clean NAB readings, then scores each new point. Confirmed-normal user readings can join the next training run. Read the beginner guide →

from isolation_forest import IsolationForest

# Train on clean examples. Known NAB anomaly windows
# are held out and used later to evaluate the model.
forest = IsolationForest(
    trees=40,
    sample_size=128,
    contamination=0.02,
)
forest.fit(clean_training_features)

score = forest.score(new_reading_features)
is_anomaly = forest.predict(new_reading_features)
label = "ANOMALOUS" if is_anomaly else "NORMAL"
print(label, score)
